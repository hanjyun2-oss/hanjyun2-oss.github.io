SIMULATED CREDIT DEMO DATA / DATOS SIMULADOS PARA CRÉDITO

portfolio-150.csv contains 150 fictional companies in five illustrative categories, 30 per category. Each of the numbered CSV files contains 30 of those same records for one category.
The currencies and amounts are simulated. The files use the existing seven-field CSV format. No records represent real people or businesses.

01 Routine: no example threshold triggered.
02 Financing: request relative to revenue reaches the example threshold.
03 Debt: current debt plus the proposed request reaches the example threshold.
04 Collections: receivable days reach the example threshold.
05 Combined: more than one category is triggered.

The overview uses simple example rules, not a bank policy. The model analyzes one selected record at a time. Suggested questions and findings require human review; they do not approve or disburse a loan.
