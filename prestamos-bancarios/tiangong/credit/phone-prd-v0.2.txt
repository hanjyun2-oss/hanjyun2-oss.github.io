# 银行小微企业信贷大屏 Demo｜手机端开发 PRD v0.2

## 1. 产品范围

本 PRD 仅覆盖大屏左侧的**手机端交互**，用于展示银行客户经理从企业评估到风险处置的完整操作流程。

右侧“天工系统、本体引擎、实体关系、证据链和规则链”暂不纳入本版开发范围。

主角企业：

> 金穗丰源农业发展有限公司  
> 行业分类：农业  
> 企业类型：小微农业经营主体

五个业务步骤：

```text
1. 前期企业评估
2. 金融产品匹配
3. 放款
4. 贷后持续监控与风险预警
5. 资产重组方案设计
```

第 1 步内部拆分为三个手机页面：

```text
企业评估清单
→ 企业深度画像
→ 客户档案与现场尽调
```

---

## 2. 核心业务流程

```text
进入企业评估清单
→ 客户经理手动选择一家企业
→ 查看企业深度画像和现存风险
→ 创建客户档案
→ 完成 7 项固定尽调 + 2 项农业特别项
→ 上传材料并回写数据入库
→ 进入产品匹配
→ 确认产品和额度
→ 放款中
→ 已放款
→ 贷后持续监控
→ 系统提示风险信号
→ 客户经理人工判断
→ 启动资产重组方案
```

核心原则：

1. 系统提供数据和风险信号，不自动替客户经理做最终判断。
2. 企业资质是加分项，不能替代偿债能力判断。
3. 现场尽调数据必须上传、核验并回写入库后，才允许进入产品匹配。
4. 风险预警不等同于不良结论，最终结论由客户经理确认。
5. 所有操作、材料和结果沉淀到客户档案。

# 4. 页面详细需求

## P01 企业评估清单

### 页面目标

展示待评估企业，供银行客户经理手动选择企业。

### 页面内容

页面标题：

> 企业评估  
> 待评估企业 7 户

顶部操作：

```text
[搜索企业名称] [行业筛选] [状态筛选]
```

企业列表字段：

- 企业名称
- 行业分类
- 推荐来源
- 融资需求
- 当前状态
- 资料完整度
- 现场尽调状态

企业示例：

| 企业名称 | 行业分类 | 当前状态 |
|---|---|---|
| 珠海澜衡精密装备有限公司 | 精密装备制造 | 待评估 |
| 华南建拓建筑工程有限公司 | 建筑工程 | 审慎关注 |
| 金穗丰源农业发展有限公司 | 农业 | 主体待核验 |
| 湾区联盛商贸有限公司 | 商贸流通 | 资料待补 |
| 鸿图新材料有限公司 | 新材料 | 资质待核验 |
| 华南盛源能源有限公司 | 火电 | 审慎准入 |
| 鑫达融资租赁有限公司 | 融资租赁 | 不纳入普惠范围 |

### 交互动作

1. 输入企业名称，实时筛选列表。
2. 点击“行业筛选”，选择农业、建筑、火电、融资租赁等行业。
3. 点击“状态筛选”，选择待评估、资料待补、审慎关注等状态。
4. 点击企业卡片，卡片高亮并显示“已选择”。
5. 点击底部按钮“查看企业画像”，进入 P02。
6. 返回清单后，保留筛选条件和上次选择状态。

### 规则

- 系统不得自动选中企业。
- 系统只展示标签、状态和提示。
- 不在该页面直接显示“授信通过”或“授信拒绝”。

## P02 企业深度画像

### 页面目标

展示客户经理选中企业的主体、行业、经营、财务、资质和风险情况。

### 页面顶部

```text
金穗丰源农业发展有限公司
农业｜小微企业｜建议继续核验
```

顶部标签：

```text
[企业画像] [现存风险]
```

### 企业画像内容

#### 主体与行业

```text
小微企业属性：符合
农业经营主体：已登记
农场经营基础：待核验
实际种植规模：待核验
行业准入：通过
行业风险：季节性及自然风险需关注
```

#### 经营与财务

```text
主营业务：粮食种植、农产品初加工及销售
经营基地：自有及承租农场约3,200亩
员工人数：58人
营业收入：5,280万元
开票收入：4,960万元
纳税额：120万元
现有银行融资：1,200万元
本次融资需求：800万元
```

固定说明：

> 已开票、已纳税收入优先作为经营真实性判断依据，客户口头陈述仅作为辅助信息。

#### 资质与荣誉核验

采用对钩和叉的清单：

```text
✓ 农业经营主体备案      已核验
✓ 农场或经营基地         已核验
✓ 市级农业龙头企业      已核验
✓ 绿色食品认证          已核验
✓ 省级示范家庭农场      待核验
✓ 农产品质量认证        待核验
× 专精特新中小企业      未发现
× 科技型中小企业        未发现
× 雏鹰企业              未发现
× 瞪羚企业              未发现
× 专精特新“小巨人”      未发现
× 单项冠军              未发现
```

状态定义：

- `✓`：已发现该资质
- `×`：当前未发现该资质
- 已核验：真实性和有效期已确认
- 待核验：已发现，但仍需补充证明
- 已失效：证书已过有效期

### 现存风险页

页面顶部：

```text
当前风险：3 项关注
重大风险：0 项
待核验事项：2 项
```

风险示例：

```text
! 农业经营收入季节性明显
! 农产品价格波动可能影响现金流
! 主要客户回款周期较长
```

点击风险卡片后展开：

- 风险来源
- 影响判断
- 相关资料
- 建议核验动作

固定提示：

> 若未来偿债能力明显不足，即使资料齐全或具备资质，也不建议强行推进授信。

### 交互动作

1. 点击主体、行业、经营财务等模块，展开或收起详情。
2. 点击资质条目，查看证书编号、有效期、发证机构和核验记录。
3. 点击风险卡片，查看风险证据和建议动作。
4. 点击“标记待核验”，将风险加入现场尽调任务。
5. 点击“创建客户档案并发起现场尽调”，创建 P03 客户档案。

## P03 客户档案与现场尽调

### 页面目标

建立客户档案，管理历史材料、当前任务、核查进度和数据回写。

### 创建客户档案

点击按钮后弹出确认框：

```text
是否创建客户档案？

企业：金穗丰源农业发展有限公司
任务：授信前现场尽调
```

确认后显示：

```text
客户档案已创建
档案状态：现场尽调中
当前进度：0 / 9
```

档案模块：

```text
[档案总览] [历史材料] [现场任务] [操作记录]
```

### 固定现场核查项

```text
□ 企业车辆及停车情况
□ 员工数量及实际在岗情况
□ 门卫及来访登记
□ 生产车间
□ 设备数量与实际使用状态
□ 会计财务报表
□ 开票收入、纳税额及回款凭证
```

### 农业行业特别项

```text
□ 农场或经营基地
□ 实际种植规模
```

### 单项任务操作

点击某一任务后进入详情：

```text
任务名称
核查说明
[上传照片]
[上传文件]
[填写访谈记录]
[填写核查备注]
[选择核查结果]
```

核查结果：

```text
已核实
存在异常
待补充
```

任务状态：

```text
待核查 → 已上传 → 已核实
```

### 完成与回写

所有任务完成后显示：

```text
固定核查：7 / 7
农业特别项：2 / 2
材料完整度：100%
```

点击：

> 提交核验结果

系统检查：

- 是否仍有待核查任务；
- 财务报表、开票、纳税和回款凭证是否上传；
- 农场和种植规模是否完成核验；
- 是否存在未处理异常。

检查通过后，点击：

> 回写数据入库

回写过程：

```text
正在回写数据……
企业画像已更新
风险信息已更新
现场材料已归档
```

完成状态：

```text
现场尽调：已完成
数据回写：成功
```

解锁按钮：

> 进入产品匹配

若存在“存在异常”任务，必须补充处理意见或确认风险后，才允许回写。

### 匹配依据

```text
内部评级：B+

经营风险：关注
```

点击数据项，可查看：

- 数据来源
- 关联材料
- 更新时间
- 核验状态


### 确认方案

```text
期限：12个月
```

```text
贷后风险预警
```

### 系统预警卡片

```text
系统发现：开票收入连续两期下降

系统发现：主要客户回款周期延长
```

- 预警类型


### 人工核查

点击：

> 发起核查

经理可上传：

- 现场核查记录
- 客户访谈
- 主要客户回款凭证
- 经营变化说明

### 经理风险判断

选择：

```text
经营基础：正常 / 有变化 / 明显恶化
还款意愿：正常 / 需关注 / 不明确
还款能力：可覆盖 / 存在缺口 / 明显不足
```

最终结论：

```text
暂无实质风险
列入关注名单
风险预警
重大风险预警
```

点击：

> 提交风险判断

若选择“列入关注名单”：

```text
已加入重点跟踪

```

> 启动风险缓释评估

进入 P07。

固定提示：

> 风险不一定先表现为欠息，更常见的是本金到期无法偿还、续贷失败、他行逾期、收入明显下滑或当地口碑恶化。

## P07 资产重组方案设计

### 页面目标

根据客户还款意愿、经营基础和未来现金流，设计风险缓释和资产重组方案。

### 进入条件

```text
风险预警已确认
客户经理已提交风险判断
```

### 重组条件判断

经理选择：

```text
还款意愿：较强 / 需关注 / 不明确
经营基础：稳定 / 有变化 / 明显恶化
未来现金流：可覆盖 / 部分覆盖 / 无法覆盖
农场经营：持续 / 有变化 / 停滞
种植规模：稳定 / 缩减 / 无法核实
```

若经营基础明显恶化或还款意愿不明确，显示：

> 当前不满足优先重组条件，建议进入收缩授信、催收或资产处置流程。

### 风险缓释方式

```text
重组 + 分期压降
展期
借新还旧
继续收息
收缩授信及资产处置
```

点击方案卡片，展示：

- 适用条件
- 方案目标
- 风险提示
- 需要补充的材料

### 重组方案填写

选择“重组 + 分期压降”后：

```text
当前贷款余额：600万元
重组期限：6个月
首期压降：100万元
剩余本金：500万元
后续回收期数：5期
利息安排：继续收息
```

系统实时计算：

```text
预计回收本金：600万元
预计处置周期：6个月
方案状态：草案
```

### 方案校验

系统检查：

- 是否有明确还款来源；
- 分期金额是否匹配现金流；
- 是否无限期延后风险；
- 是否需要补充催收或现场材料；
- 是否触发二次重组限制。

固定提示：

```text
重组不得掩盖真实风险
不得无限期延后风险暴露
方案必须匹配实际回收能力
```

### 提交动作

按钮：

> 保存方案草案

保存后：

```text
方案状态：草案
```

点击：

> 提交重组审批

弹出确认框：

```text
方案类型：重组 + 分期压降
预计回收本金：600万元
预计处置周期：6个月
是否提交审批？
```

确认后：

```text
已提交重组审批
客户档案已更新
后续跟踪任务已创建
```

# 6. 全局交互规则

1. 页面底部固定主操作按钮。
2. 所有提交动作都需要二次确认。
3. 已提交信息默认只读，需点击“编辑”后修改。
4. 返回页面不丢失已填写数据。
5. 风险信号可以由系统生成，但风险结论必须由客户经理提交。
6. 所有材料上传后显示上传人、上传时间和材料状态。
7. 所有阶段状态写入客户档案时间线。
8. 数据回写失败时允许重新回写。
9. 必填项未完成时，主按钮置灰，并展示缺失原因。
10. 所有金额、企业数据和风险数据均为 Demo 模拟数据。

# 7. 开发验收标准

- 企业清单展示 5—8 户企业，并包含行业分类。
- 客户经理可以手动选择企业。
- 农业企业画像包含农业经营主体、农场和实际种植规模。
- 资质核验使用对钩和叉清单。
- 现场尽调包含 7 项固定任务和 2 项农业特别项。
- 发起现场尽调后自动创建客户档案。
- 客户档案可以查看历史材料、当前任务和操作记录。
- 所有尽调任务完成且数据回写成功后，才解锁产品匹配。
- 产品匹配支持产品选择和额度调整。
- 放款页面只有“放款中”和“已放款”两个状态。
- 贷后页面展示经营、财务、征信、当地口碑/舆情等独立信源。
- 系统预警不直接等同于最终风险结论。
- 客户经理可以提交风险判断。
- 风险预警后可以进入资产重组方案设计。
- 客户档案保存完整流程、材料、判断和后续任务。
